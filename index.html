MACHINE LEARNING NASA KC1 BENCHMARK 0.82 ROC-AUC

Software Defect Risk Engine

An end-to-end Machine Learning system and static analysis pipeline that evaluates Python source modules to predict defect-risk probability (Low / Medium / High) and reports key risk-driving factors using SHAP explainability, backed by a production FastAPI REST backend.

  • Trained on the NASA KC1 benchmark (2,109 modules, ~15% defective) to score code defect probability.
  • Engineered operand/operator density metrics and tuned XGBoost using 5-fold stratified RandomizedSearchCV with class-imbalance weighting (scale_pos_weight).
  • Achieved 0.82 ROC-AUC and 84% recall on held-out test set (317 samples), prioritizing recall for code review.
  • Integrated SHAP explainability to display which structural metrics (cyclomatic complexity, branch count) raise or lower risk scores.
  • Extracted LOC, cyclomatic complexity, and Halstead metrics using Python's ast module and Radon.
  • Deployed a FastAPI backend with Pydantic validation, endpoints for code analysis, and SQLAlchemy ORM scan-history CRUD.

Used Car Price Predictor with Recommender

A production ML pricing service trained on 2,059 Indian used-car listings that accurately predicts fair market valuations using an XGBoost regressor (R² = 0.89) and surfaces comparable market listings using a K-Nearest Neighbors recommendation engine.

  • Trained on 2,059 Indian used-car listings across 20 features to predict fair prices and recommend 5 closest comparable listings.
  • Cleaned data via median/mode imputation, regex numeric extraction from text fields (Engine, Max Power, Max Torque), and missing-value heatmap analysis.
  • Engineered features including Car Age and model-popularity frequency encoding, with one-hot encoding for 8 categorical variables.
  • Trained an XGBoost Regressor achieving R² of 0.89 (MAE Rs. 2.66 lakh) on an 80/20 train-test split.
  • Integrated a K-Nearest Neighbors (KNN) recommender over price and feature distributions to surface top comparable listings.
  • Deployed as a FastAPI service with a /predict endpoint, Pydantic input validation, and serialized model artifacts loaded via joblib.
